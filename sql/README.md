# 🛒 Retail Sales & Customer Behaviour SQL Analysis

## 📌 Project Overview
This project is a SQL-based retail analytics system designed to simulate a real-world business environment. It analyzes sales performance, customer behaviour, and product trends using a relational database structure.

The goal is to demonstrate practical SQL skills required for Data Analyst and Data Engineer roles.

---

## 🎯 Business Objectives
The project answers key business questions such as:

- What is the total revenue generated?
- Which products and categories perform best?
- Who are the top customers by spending?
- How many orders are placed over time?
- How does sales performance change daily?
- What are customer purchasing patterns?

---

## 🗄️ Database Schema

The database consists of four relational tables:

- **customers** → stores customer information
- **products** → stores product details and pricing
- **orders** → stores order transactions
- **order_items** → stores item-level sales data

---

## 📊 SQL Analysis Performed

This project includes the following analyses:

- Total revenue calculation
- Total number of orders and customers
- Revenue by product category
- Top 5 best-selling products
- Top customers by total spending
- Number of orders per customer
- Average order value (AOV)
- Daily sales trend analysis
- Customer ranking using SQL Window Functions
- RFM customer segmentation analysis
